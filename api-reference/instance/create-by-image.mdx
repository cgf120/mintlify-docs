# 通过镜像创建实例

使用个人镜像或算力市场镜像创建一个新的GPU实例。

<Info>
  `idempotency_key` 可选。传入后，同一用户使用相同幂等键重试创建时最多产生一台实例，不会重复扣费。超时重试、网关重发等场景建议始终携带稳定的业务单号或 UUID。不传时行为与历史接口一致。
</Info>

## 请求参数

<ParamField body="image_uuid" type="string" required>
  镜像uuid，可通过查询镜像接口获取
</ParamField>

<ParamField body="gpu_uuid" type="string" required>
  GPU型号uuid
</ParamField>

<ParamField body="gpu_nums" type="integer" required>
  使用GPU数量，可选值：1/2/4/8
</ParamField>

<ParamField body="charging_type" type="integer">
  计费类型。`1` 按量（默认），`2` 包日，`3` 包周，`4` 包月
</ParamField>

<ParamField body="charging_num" type="integer">
  计费数量（几天/几周/几月）。包年包月时默认 `1`
</ParamField>

<ParamField body="idempotency_key" type="string">
  幂等键，由调用方生成。长度 1～128（trim 后），建议可打印 ASCII。同一 API Key 对应用户下，相同 key 在成功记录有效期内（默认 7 天）最多创建一台实例。推荐使用业务订单号、任务 ID 或 UUID
</ParamField>

## 幂等行为

| 场景 | `code` | `data.idempotent` | 说明 |
| --- | --- | --- | --- |
| 不传 `idempotency_key` | `0` | `false` | 每次请求都会新建实例，与历史行为一致 |
| 有 key，首次创建成功 | `0` | `false` | 真实创建并扣费 |
| 有 key，相同参数重放 | `0` | `true` | 返回同一 `instance_uuid`，不再次创建或扣费；`status` 等字段为当前实例视图 |
| 有 key，创建进行中 | 非 `0` | - | `msg` 为创建中提示，`data.instance_uuid` 为已预分配 uuid，可用 [查询实例](/api-reference/instance/info) 轮询 |
| 有 key，参数与首次不一致 | 非 `0` | - | 拒绝创建，例如改了 `gpu_nums` / `image_uuid` |
| 有 key，TTL 内实例已销毁 | 非 `0` | - | 拒绝新建，需更换 key 或等记录过期后再用 |

纳入参数一致性校验的字段：`image_uuid`、`gpu_uuid`、`gpu_nums`、`charging_type`、`charging_num`。`create_by_pod` 与 `create_by_image` 共用同一用户下的 key 命名空间，不可混用同一 key。

成功记录默认保留 7 天；创建中（pending）默认约 30 分钟。过期后同一 key 可再次用于新的创建意图。

## 幂等相关错误

常见 `msg`（HTTP 多为 200，业务 `code` 非 0）：

| `msg` | 说明 |
| --- | --- |
| `idempotency_key 不合法` | key 为空、超长或含控制字符 |
| `idempotency_key 与已有请求参数不一致` | 同 key 但创建意图参数不同 |
| `实例创建中，请使用 instance_uuid 查询状态` | 首次创建仍在进行，`data` 含预分配 `instance_uuid` |
| `幂等记录有效但实例已销毁，请更换 idempotency_key` | TTL 内实例已销毁，不可用同 key 再建 |
| `幂等记录失败且不可重试，请更换 idempotency_key` | 不可重试失败态，需更换 key |

可重试失败（如余额不足、参数校验失败且未产生有效实例）允许同一 key 在修正条件后再次创建。

## 代码示例

<CodeGroup>

```python Python
import requests
from datetime import datetime
import uuid

url = "https://www.chenyu.cn/api/open/v2/instance/create_by_image"
headers = {
    "Authorization": "Bearer your_api_key",
    "Content-Type": "application/json"
}

data = {
    "image_uuid": "img_12345678-1234-1234-1234-123456789012",
    "gpu_uuid": "gpu_87654321-4321-4321-4321-210987654321",
    "gpu_nums": 2,
    "idempotency_key": f"order-{uuid.uuid4()}"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()

if result['code'] == 0:
    instance = result['data']
    create_time = datetime.fromtimestamp(instance['create_time'])

    print(f"实例创建成功!")
    print(f"实例UUID: {instance['instance_uuid']}")
    print(f"是否幂等重放: {instance.get('idempotent', False)}")
    print(f"实例名称: {instance['title']}")
    print(f"镜像名称: {instance['image_name']}")
    print(f"GPU名称: {instance['gpu_name']}")
    print(f"GPU数量: {instance['gpu_nums']}")
    print(f"创建时间: {create_time.strftime('%Y-%m-%d %H:%M:%S')}")

    if instance.get('server_url'):
        print("服务访问地址:")
        for url in instance['server_url']:
            print(f"  - {url}")
else:
    print(f"创建失败: {result['msg']}")
    if isinstance(result.get('data'), dict) and result['data'].get('instance_uuid'):
        print(f"可查询的实例UUID: {result['data']['instance_uuid']}")
```

```javascript JavaScript
const axios = require('axios');
const { randomUUID } = require('crypto');

const url = 'https://www.chenyu.cn/api/open/v2/instance/create_by_image';
const headers = {
    'Authorization': 'Bearer your_api_key',
    'Content-Type': 'application/json'
};

const data = {
    image_uuid: 'img_12345678-1234-1234-1234-123456789012',
    gpu_uuid: 'gpu_87654321-4321-4321-4321-210987654321',
    gpu_nums: 2,
    idempotency_key: `order-${randomUUID()}`
};

axios.post(url, data, { headers })
    .then(response => {
        const result = response.data;

        if (result.code === 0) {
            const instance = result.data;
            const createTime = new Date(instance.create_time * 1000);

            console.log('实例创建成功!');
            console.log(`实例UUID: ${instance.instance_uuid}`);
            console.log(`是否幂等重放: ${instance.idempotent === true}`);
            console.log(`实例名称: ${instance.title}`);
            console.log(`镜像名称: ${instance.image_name}`);
            console.log(`GPU名称: ${instance.gpu_name}`);
            console.log(`GPU数量: ${instance.gpu_nums}`);
            console.log(`创建时间: ${createTime.toLocaleString()}`);

            if (instance.server_url && instance.server_url.length > 0) {
                console.log('服务访问地址:');
                instance.server_url.forEach(url => {
                    console.log(`  - ${url}`);
                });
            }
        } else {
            console.log(`创建失败: ${result.msg}`);
            if (result.data && result.data.instance_uuid) {
                console.log(`可查询的实例UUID: ${result.data.instance_uuid}`);
            }
        }
    })
    .catch(error => {
        console.error('Error:', error.response?.data || error.message);
    });
```
